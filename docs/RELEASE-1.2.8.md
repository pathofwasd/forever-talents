# Forever Talents 1.2.8

Send a build as a link, and keep the tree in view while planning on a phone.

- **Build links:** website **Share → Copy build link**, or addon **Share → Web link → Ctrl+C**.
  Friends open the link, review the build, then choose **Load build**. Links carry class, race,
  level, talents and exact point order. No account needed. Both versions also accept links through
  Import.
- **Mobile talent panel:** tap a talent for a bottom panel. Use its pinned **+ / −** buttons while
  scrolling the tree, or tap another talent to inspect it. Extra ranks and related skills expand
  inside the panel.
- **Talent inspection:** hover a talent to see its affected skills. **Alt-click** opens full ranks,
  point controls and skill links in both the addon and website. Right-click still removes a point;
  keyboard Enter and mobile tap open web details.
- **Clear skill levels:** **🔓 Lv. 22 · Max rank 5 Lv. 54**, for example. The first level is the
  skill’s unlock; the second belongs to the displayed rank. A next-rank line, such as **🔒 Rank 4
  Lv. 46**, appears only when another rank exists. The lock disappears at the required level.
  Imported spellbook ranks are marked **Trained**. Available in both interfaces, including Classic /
  Simple view.

Saved profiles, checkpoints, character captures and existing sharing strings remain compatible.
Links share talent builds; stats, gear and full libraries have their existing separate exports. Game
data is unchanged.

## Download and install

Scroll to **Assets** on this release page and download **ForeverTalents.zip**. Expand Assets if
needed. The “Source code” archives are for development.

1. Close World of Warcraft.
2. Extract the ZIP and copy **ForeverTalents** into the Forever client’s `Interface/AddOns` folder.
3. Check that `Interface/AddOns/ForeverTalents/ForeverTalents.toc` exists without extra nesting.
4. Enable the addon and type `/ftc`.

When updating, move the previous addon folder outside AddOns as a backup. Keep your `WTF` folder; it
contains saved builds and settings. If files were updated while playing, use `/reload`.

The [web/mobile app](https://pathofwasd.github.io/forever-talents/) uses the same engine. Accept its
update prompt to load this release; local saves remain intact. Export your full library for backups
or transfer between the addon and web app.
