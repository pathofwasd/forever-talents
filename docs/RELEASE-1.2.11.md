# Forever Talents 1.2.11

- Phone talent +/− controls keep the tree in place. The panel stays the same size, rank details
  scroll inside it, and expanded details remain open while editing.
- Desktop **Checkpoints & order** opens a roomy dedicated workspace. Larger nodes wrap their titles,
  deep branches scroll, and the selected node comes into view. Phones keep the **Builds** tab.
- The addon’s **Checkpoints** tab opens its full graph. Save and share actions return to that graph.
- **Check for updates** in the web footer and phone **More** menu shows whether your installed
  version is current or downloading. **Update now** appears only when the complete release is
  cached.
- Blocked removals explain which talent needs supporting points, for example **9/10**. Row 3 needs
  ten points spread across earlier rows; it does not require five points in each row. Move a point
  into an earlier row first when changing those supporting talents.

Existing libraries, checkpoint branches, Auto/Undo/Redo and sharing formats remain compatible. Game
data and talent layouts are unchanged.

## Download and install

Scroll to **Assets** below and download **ForeverTalents.zip**. Expand Assets if needed. The “Source
code” archives are for development.

1. Close World of Warcraft.
2. Extract the ZIP and copy **ForeverTalents** into the Forever client's `Interface/AddOns` folder.
3. Check that `Interface/AddOns/ForeverTalents/ForeverTalents.toc` exists without extra nesting.
4. Enable the addon and type `/ftc`.

For updates, move the previous addon folder outside AddOns as a backup. Keep your `WTF` folder; it
contains your saved builds and settings. If files are replaced while playing, use `/reload`.

The [web/mobile app](https://pathofwasd.github.io/forever-talents/) uses the same engine. Accept its
update prompt to load this release. Export your full library for backups or transfer between the
addon and web.
