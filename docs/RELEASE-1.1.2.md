# Forever Talents 1.1.2

A free, unofficial talent planner for World of Warcraft Forever.

## Download the addon

**Scroll to the Assets section at the bottom of this release and click `ForeverTalents.zip`.** If
Assets is collapsed, click it to expand the list. Use **ForeverTalents.zip** for installation; the
**Source code (zip)** and **Source code (tar.gz)** entries are developer downloads.

## Install

1. Download **ForeverTalents.zip** from Assets below.
2. Extract it and copy the **ForeverTalents** folder into your game's **Interface/AddOns**
   directory.
3. Check that the final path is `Interface/AddOns/ForeverTalents/ForeverTalents.toc`.
4. Enable **Forever Talents** in the character-selection AddOns menu.
5. Log in and type **`/ftc`** to open the planner.

No other addons are required. To update, replace the addon folder and keep your `WTF` folder, which
contains your saved builds.

## Features

- All nine classes with original talent layouts, rank descriptions and prerequisite checks.
- Searchable skills and racials, rank unlock levels and persistent talent highlights.
- Auto level, undo/redo, exact talent spending order and branching checkpoints.
- Copy/paste sharing for builds, character stats and entire saved libraries.
- Clickable addon-whisper build sharing.
- Damage and healing estimates with optional advanced settings.

## Web and mobile

[Open the browser version](https://pathofwasd.github.io/forever-talents/)

Works on desktop and mobile. Install it through your browser and use it offline after it shows
**Ready offline**. Saves stay on your device; export your library to transfer or back it up.

## Compatibility

Bundled data: **Forever 1.60.1, build 69876**. Damage and healing results estimate individual skill
uses, not full combat rotations.
